# px64 (Pulse Extended 64-bit Real-Time Architecture) ISA & VM 仕様書 (日本語)

---

## 1. 概要とアーキテクチャ設計原則

`px64` は、LatencyOS カーネル内に直接実装された、決定論的 64-bit レジスタマシン命令セットアーキテクチャ（ISA）および仮想マシンです。ハードリアルタイム・ストリーミング処理において、最悪実行時間（WCET）を厳格に保証し、ブート後の動的ヒープ確保をゼロにする目的で設計されています。

### 設計原則:
1. **32-bit (4 バイト) 固定長命令**: すべての命令長を 4 バイト固定とし、可変長命令のデコードオーバーヘッドを排除して $O(1)$ 定数時間で命令をフェッチ・実行します。
2. **20 本のレジスタ構成**: 16 本の 64-bit 汎用レジスタ（x64 互換名 `$rax`〜`$r15`）＋ 4 本のハードウェア DMA スロットレジスタ（`#f0`〜`#f3`）。
3. **タグ付きポインタによるゼロアロケーション**: 文字列やコマンドライン引数は 64-bit 整数の上位ビットを用いたタグ付きポインタ（`STR_TAG: 0x4000_...`, `ARG_TAG: 0x2000_...`）で表現し、ヒープ確保を完全排除。
4. **ハードウェア直結の時限ガード**: CPU のシリアル化 TSC カウンタと直結した時限監視命令（`WITHIN_START`, `WITHIN_END`, `DROP`）を ISA レベルで提供。
5. **決定論的ステップ数制限**: 1 回の実行につき最大 10,000 命令のステップ上限を設け、無限ループやデッドロックを防止。

## 2. レジスタマップ (20 レジスタ)

| レジスタ ID | 正式名称 | x64 エイリアス | 主な用途 |
|---|---|---|---|
| `0` | `$rax` | `$r0` | アキュムレータ、式評価の主結果、関数の戻り値 |
| `1` | `$rcx` | `$r1` | カウンタ、ユーザー変数スロット 1 |
| `2` | `$rdx` | `$r2` | データ、ユーザー変数スロット 2 |

| `5` | `$rbp` | `$r5` | ベースポインタ名、ユーザー変数スロット 5 |
| `6` | `$rsi` | `$r6` | ソースインデックス、ユーザー変数スロット 6 |
| `7` | `$rdi` | `$r7` | ディスティネーションインデックス、ユーザー変数スロット 7 |
| `8` | `$r8` | `$r8` | ユーザー変数スロット 8 |
| `9` | `$r9` | `$r9` | ユーザー変数スロット 9 |
| `10` | `$r10` | `$r10` | ユーザー変数スロット 10 |

## 3. 32-bit 固定長命令エンコーディング

すべての `px64` 命令は 4 バイト境界に配置されます。

```text
+----------------+----------------+----------------+----------------+
| Byte 0 (Opcode)| Byte 1 (Rd)    | Byte 2 (Rs1)   | Byte 3 (Rs2)   |
| [7:0]          | [7:0]          | [7:0] / Imm_hi | [7:0] / Imm_lo |
+----------------+----------------+----------------+----------------+
```

## 4. 完全命令セット一覧

| Opcode | ニーモニック | オペランド | エンコード | 動作・セマンティクス | WCET |
|---|---|---|---|---|---|
| `0x00` | `NOP` | なし | `00 00 00 00` | 何もしない (No Operation) | ~1 ns |
| `0x01` | `MOV` | `Rd, Imm16` | `01 Rd Ih Il` | 16-bit 即値を Rd に代入 | ~2 ns |
| `0x02` | `MOV` | `Rd, Rs1` | `02 Rd Rs 00` | Rs1 の値を Rd に転送 | ~2 ns |
| `0x03` | `MOVS` | `Rd, Offset, Len` | `03 Rd Of Ln` | 文字列ポインタを Rd に代入 | ~3 ns |
| `0x04` | `ADD` | `Rd, Rs1, Rs2` | `04 Rd S1 S2` | 整数加算 (`Rd = Rs1 + Rs2`) | ~2 ns |
| `0x05` | `SUB` | `Rd, Rs1, Rs2` | `05 Rd S1 S2` | 整数減算 (`Rd = Rs1 - Rs2`) | ~2 ns |
| `0x06` | `MUL` | `Rd, Rs1, Rs2` | `06 Rd S1 S2` | 整数乗算 (`Rd = Rs1 * Rs2`) | ~3 ns |
| `0x07` | `DIV` | `Rd, Rs1, Rs2` | `07 Rd S1 S2` | 整数除算（0除算保護付き） | ~12 ns |
| `0x08` | `MOD` | `Rd, Rs1, Rs2` | `08 Rd S1 S2` | 整数剰余（0除算保護付き） | ~12 ns |
| `0x09` | `CMPEQ` | `Rd, Rs1, Rs2` | `09 Rd S1 S2` | 一致比較（真なら 1、偽なら 0） | ~2 ns |
| `0x0A` | `CMPNE` | `Rd, Rs1, Rs2` | `0a Rd S1 S2` | 不一致比較 | ~2 ns |
| `0x0B` | `CMPLT` | `Rd, Rs1, Rs2` | `0b Rd S1 S2` | 小なり比較 | ~2 ns |
| `0x0C` | `CMPLE` | `Rd, Rs1, Rs2` | `0c Rd S1 S2` | 以下比較 | ~2 ns |
| `0x0D` | `CMPGT` | `Rd, Rs1, Rs2` | `0d Rd S1 S2` | 大なり比較 | ~2 ns |
| `0x0E` | `CMPGE` | `Rd, Rs1, Rs2` | `0e Rd S1 S2` | 以上比較 | ~2 ns |
| `0x0F` | `JMP` | `Target16` | `0f 00 Th Tl` | 無条件ジャンプ | ~2 ns |
| `0x10` | `JZ` | `Rs1, Target16` | `10 Rs Th Tl` | `Rs1 == 0` ならジャンプ | ~3 ns |
| `0x11` | `JNZ` | `Rs1, Target16` | `11 Rs Th Tl` | `Rs1 != 0` ならジャンプ | ~3 ns |
| `0x12` | `CALL_NAT` | `Rd, FuncId, ArgReg` | `12 Rd Fn Ar` | ハードウェア組み込み命令呼出 | 処理依存 |
| `0x13` | `WITHIN_START` | `Rs1` | `13 Rs 00 00` | デッドラインタイマー開始 (Rs1: us単位) | ~15 ns |
| `0x14` | `WITHIN_END` | なし | `14 00 00 00` | デッドラインスタックをポップ | ~2 ns |
| `0x15` | `DROP` | なし | `15 00 00 00` | デッドライン超過時にフレーム破棄 | ~10 ns |
| `0x16` | `HALT` | なし | `16 00 00 00` | 実行を正常終了 | ~1 ns |

## 5. ハードウェア組み込み命令 (`CALL_NAT`) 一覧

| 関数 ID | 組み込み関数名 | シグネチャ | 説明 |
|---|---|---|---|
| `1` | `@print` | `(any) -> 0` | 文字列リテラル、引数、数値をシリアルに出力 |
| `2` | `@println` | `(any) -> 0` | 値と改行（CRLF）を出力 |
| `3` | `@tsc` | `() -> i64` | CPU のシリアル化 TSC サイクル数を取得 |
| `4` | `@rtt` | `() -> i64` | 計測された最小 RTT (ナノ秒) を取得 |
| `5` | `@rate` | `(pct: i64) -> 0` | 輻輳制御の送信帯域レート (10%..100%) を設定 |
| `6` | `@capture` | `() -> i64` | VBLANK 垂直同期付き GPU ゼロコピーフレームを取得 |
| `7` | `@send` | `(slot: i64) -> 1` | Intel e1000 PMD 経由で暗号化 SRTP 送信 |
| `8` | `@argc` | `() -> i64` | スクリプトに渡された引数の個数を取得 (0..8) |
| `9` | `@arg` | `(idx: i64) -> Tagged` | 指定インデックスの引数参照を取得 |

## 6. バイナリコンテナフォーマット (`PX64`)

```text
+-------------------------------------------------------------------------------+
| Bytes 0..3   : マジックバイト ("PX64" -> 0x50, 0x58, 0x36, 0x34)               |
| Bytes 4..5   : バージョン番号 (0x0003)                                         |
| Bytes 6..7   : バイトコード長 (CodeLen: u16 ビッグエンディアン)                |
| Bytes 8..9   : 文字列プール長 (StrLen: u16 ビッグエンディアン)                 |
| Bytes 10..11 : 定数プールエントリ数 (ConstCount: u16 ビッグエンディアン)        |
| Bytes 12..13 : レジスタ数 (0x0014 = 20 レジスタ)                               |
| Bytes 14..15 : 予約領域 (0x0000)                                               |
+-------------------------------------------------------------------------------+
| バイトコード本体 (CodeLen バイト, 4 バイトアライメントの px64 命令列)           |
+-------------------------------------------------------------------------------+
| 文字列プール本体 (StrLen バイトの UTF-8 文字列データ)                           |
+-------------------------------------------------------------------------------+
| 定数プール本体 (ConstCount * 8 バイトの 64-bit ビッグエンディアン定数)          |
+-------------------------------------------------------------------------------+
```
